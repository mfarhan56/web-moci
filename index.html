Pemilih Jaringan Wi-Fi ESP32-S3 (Wi-Fi Manager)

Klik tombol "Pindai Wi-Fi Sekitar" di atas untuk memindai jaringan Wi-Fi di sekitar robot Moci.
Hubungkan ESP32-S3 ke Jaringan Pilihan:
Sedang menghubungkan ESP32-S3 ke jaringan...
💡 Cara Kerja: Pilih Wi-Fi di Web tanpa Ketik Manual di Arduino Klik untuk buka panduan
  1. Langkah 1: ESP32-S3 pertama kali dinyalakan akan memancarkan hotspot Wi-Fi sendiri bernama Moci-Companion-AP (IP: 192.168.4.1).
  2. Langkah 2: Sambungkan HP/Laptop kamu ke Wi-Fi Moci-Companion-AP tersebut (atau colok kabel USB-C ke laptop). Buka Web Moci.
  3. Langkah 3: Klik tombol "Pindai Wi-Fi Sekitar" di atas. ESP32 menjalankan fungsi WiFi.scanNetworks() dan mengirim daftar sinyal ke web ini.
  4. Langkah 4: Klik nama Wi-Fi rumah kamu dari daftar, ketik password, lalu klik "Hubungkan ESP32 ke Wi-Fi Ini".
  5. Langkah 5: ESP32 otomatis menyimpan SSID & sandi ke dalam memori Flash permanen (NVS via Preferences.h), lalu menyambungkan diri ke router rumah kamu dan mendapatkan alamat IP baru.
  6. Hasil: Mulai sekarang, robot Moci akan selalu otomatis menyambung ke Wi-Fi rumah setiap kali dinyalakan. Kamu tidak perlu lagi mengedit atau mengetik manual SSID/password di kode Arduino sketch!
📄 Sketch Arduino lengkap siap upload telah disediakan di berkas: arduino_firmware_wifi_manager.ino

Konfigurasi USB Serial (Web Serial API)

Belum Terhubung

Sambungkan kabel data USB-C dari komputer ke port ESP32-S3. ESP32-S3 memiliki native USB CDC sehingga dapat dideteksi langsung oleh peramban tanpa driver tambahan.

SERIAL MONITOR ESP32-S3 (TX/RX)
System Menunggu koneksi serial. Klik "Sambungkan Port USB Serial" untuk memilih port COM ESP32-S3.
🌐

Konfigurasi Wi-Fi REST API (Local LAN / AP)

Siap Dihubungkan

Pastikan laptop atau HP Anda terhubung ke Access Point robot (misal: Moci-Companion-AP) atau berada pada jaringan Wi-Fi rumah yang sama.

Default AP ESP32: http://192.168.4.1 | mDNS: http://moci.local
⚡

Konfigurasi WebSocket Realtime (Port 81)

Terputus

WebSocket memberikan transmisi data instan (di bawah 10ms) untuk menggerakkan ekspresi mata, tombol kendali, dan menerima telemetri baterai/sensor secara live.

📡

Konfigurasi Web Bluetooth (BLE 5.0)

Standby

Mode Demo (Simulasi Browser Aktif)

Simulasi Aktif

Pada mode ini, seluruh respon robot (TFT 1.8", baterai 3.82V, penyimpanan 16GB, ekspresi mata, dan pemutar musik) disimulasikan secara mandiri di dalam peramban web. Sangat berguna untuk pengujian antarmuka dan presentasi sebelum firmware ESP32 diunggah.

Data ini adalah representasi simulasi browser. Hubungkan ESP32-S3 fisik melalui Pengaturan Koneksi untuk komunikasi nyata.

Solusi Masalah Jaringan (Troubleshoot)

  • Mixed Content (HTTPS vs HTTP): Jika Web Moci diakses via HTTPS (GitHub Pages) dan mencoba menghubungi ESP32 via HTTP lokal, browser modern akan memblokir request. Solusinya: gunakan mDNS, proxy SSL (ngrok / Cloudflare Tunnel), atau jalankan web di jaringan lokal via HTTP.
  • Header CORS: Firmware ESP32 wajib menyertakan header Access-Control-Allow-Origin: * pada respons WebServer Arduino / ESP-IDF.
  • Satu Jaringan Wi-Fi: Pastikan HP / laptop kamu terhubung ke SSID yang sama dengan ESP32-S3.

Keamanan Kredensial

  • Tanpa Password di Frontend: Web Moci tidak pernah menyimpan kata sandi Wi-Fi atau kunci privat dalam kode statis yang dipublikasikan ke GitHub Pages.
  • Konfigurasi Mandiri: Kredensial Wi-Fi sebaiknya dikonfigurasi melalui captive portal (WiFiManager) langsung di chip ESP32-S3.
  • Akses Lokal: Seluruh komunikasi REST & transfer berkas berjalan secara peer-to-peer di jaringan lokal tanpa server perantara pihak ketiga.
